# NEXUS AI · Pre-Loss Fraud Intelligence

> Концепт команды NEXUS AI по теме «Инновации в банкинге и кибербезопасность»: модуль для любого банка РК поверх его текущего антифрода.
> **Не является продуктом банка-организатора** и не одобрен банком; логотипы и бренды банков, магазинов и площадок не используются.
> Все клиенты, счета, транзакции, номера, МФО и атаки — синтетические. Демо-домены — только в зоне `.test`, новые номера карт — в диапазоне `9999`.

**NEXUS — одна петля защиты для банка, где атака на одного человека спасает деньги другого: реквизит, который мошенник продиктовал роботу-приманке, через минуту удерживает перевод следующей жертвы.**

Мошенник звонит Гульнаре-апа, 63, «из службы безопасности банка». NEXUS поднимает тревогу во время разговора, звонок уходит
роботу-приманке на номере-ловушке, и тот выспрашивает «безопасный счёт». Через минуту Сауле Д., 67, пытается перевести 380 000 ₸ на этот
же счёт — перевод **удержан для проверки**, её сын Ерлан получает запрос в разделе «Близкие». Всё это — симуляция на синтетических данных.

```
DETECT → UNDERSTAND → PREDICT → PROTECT → INVESTIGATE → RECOVER
   ↑                                                      │
   └──── реквизиты из ловушки и из обращений пострадавших ─┘
```

Три главные идеи: **робот-приманка** (реквизиты дропов до первой жертвы), **«Ваш обычный перевод»** (индекс отклонения 0–100, не вероятность),
**«Мои правила»** (клиент заранее задаёт правила; ослабить правило — только через 24 ч и не во время звонка).
Плюс две новые защиты вне звонка: **«Не стань дропом»** и **«Кредитный замок»** (ниже).

## Как запустить

Сайт статический: без сборки и базы данных. Состояние — в `localStorage` (`nexus_ai_*`), вкладки синхронизируются через `BroadcastChannel`.

```powershell
# Windows, без Node.js и Python
powershell -NoProfile -ExecutionPolicy Bypass -File .\serve.ps1 -Open          # http://localhost:8080/stage.html
powershell -NoProfile -ExecutionPolicy Bypass -File .\serve.ps1 -Port 8081 -Open
```

Подойдёт любой статический сервер (`npx serve`, `python -m http.server`). **Не открывайте через `file://`** — вкладки клиента и банка
не увидят друг друга. Микрофону нужен HTTPS или `localhost`. Без сервера LLM всё работает на офлайн-движке.

| Страница | Что это |
|---|---|
| `stage.html?fresh=1` | Сцена для жюри: **7 шагов + финал**, около 5 минут. В степпере ▶ (вступление), 1–7, ★ (финал). Клавиши: **A** автопилот, **R** сброс, **F** полный экран, **L** LLM вкл/выкл, **N** заметки ведущего. Если клавиши не доходят до страницы — кнопка «Автопилот» |
| `stage.html?short=1&fresh=1` | 3 минуты (видео и отборочный тур); автопилот **A** заканчивает на 3:00 |

| `client.html` | Кабинет клиента, **5 разделов**: Главная · Звонок · Платежи · Правила · Помощь (на телефоне — нижняя панель). В шапке — тег «демо-данные» (что работает в прототипе) и красная кнопка SOS |
| `bank.html` | Панель банка (Fraud Fusion Center): Сейчас · Мониторинг · Граф · Счета · Инциденты · Аналитика. На «Сейчас» — атака в реальном времени, очередь аналитика и плитки «Новые функции» |

### Необязательный сервер LLM (`/api/chat`)

Claude используется для объяснений и реплик приманки; решения по переводам LLM не принимает и операций не выполняет.
Сервер маскирует ПДн (счёт, карта, телефон, ИИН, имена) перед вызовом модели — `server/mask-pii.mjs`, копия в браузере — `NX.maskPII`.

| Переменная | Значение |
|---|---|
| `ANTHROPIC_API_KEY` | **обязательно для LLM**, только в переменных окружения сервера, никогда в коде |
| `NEXUS_ALLOWED_ORIGINS` | адрес деплоя (например `https://<ваш-домен>`); без неё проверка Origin выключена |
| `NEXUS_MODEL` | модель (по умолчанию `claude-opus-5-5`) |
| `NEXUS_RATE_PER_MIN` / `NEXUS_DECOY_RATE_PER_MIN` / `NEXUS_GLOBAL_PER_MIN` | 20 / 30 / 60 запросов в минуту |
| `NEXUS_CHAT_TIMEOUT_MS` / `NEXUS_DECOY_TIMEOUT_MS` | 7500 / 4500 мс |

- **Vercel:** импорт репозитория, Framework Preset *Other*, переменные окружения → Redeploy. Проверка: `GET /api/chat` → `{"ok":true,...}`, `GET /api/chat?deep=1` — реальный ответ.
- **Netlify:** импорт из репозитория (перетаскивание папки не собирает функции), те же переменные.
- Rate-limit живёт в памяти одного экземпляра функции — **задайте лимит расходов в Anthropic Console**.
- `@anthropic-ai/sdk` в `package.json` указан как `latest`: перед демо закрепите проверенную версию и закоммитьте lock-файл.
- `vercel.json` и `netlify.toml` отдают 404 на `server/`, `netlify/`, `api/chat.js`, `package*.json`, `serve.ps1` и конфиги. `docs/` — обычная статика без секретов.
- Локально `serve.ps1` отвечает на `/api/chat` `{ok:false}`, и страницы сами переходят на офлайн-движок.

## Три уровня реальности

Один источник на всех страницах — массив `NX.ui.FEATURES` в `assets/js/ui-kit.js`; его показывает поповер «Что работает в прототипе»
(тег «демо-данные» в кабинете, «Демо · синтетические данные» в банке и на сцене).

| Работает в прототипе | На симулированных данных | Требует интеграции с API банка |
|---|---|---|
| Индекс риска звонка после каждой фразы, детектор давления (7 стадий, RU/KZ), «Ваш обычный перевод», решение по переводу (пропустить / подтвердить / пауза 60 с / удержать), «Мои правила» и правило 24 часов, «Близкие» без реквизитов, стоп-лист со статусами и четырьмя глазами, цепочки дропов, обращение «Меня обманули», маскирование ПДн, офлайн-приманка, логика «Не стань дропом» и «Кредитного замка» | Демо-звонок озвучен синтезом речи; мошенника играет судья или автопилот; доверенное лицо — вкладка того же браузера; поток операций, граф и история клиентов; отметка «Звонит настоящий банк» идёт по шине браузера; переводы незнакомцев, куратор, заявки МФО и устройство-фабрика | Настоящие звонки (Mobile SDK: факт звонка; речь на устройстве — Android, по согласию); номер-ловушка у оператора; удержание реального перевода в процессинге; push доверенному лицу; подпись событий и аттестация; отметка «звонит банк» с сервера банка; обмен с АФЦ НБРК; кредитное бюро и государственный механизм отказа от займов |

### Защиты вне звонка: четыре модуля

Все четыре подают сигналы в тот же стоп-лист (`NX.iocs`) и в панель банка. Все — симуляция на синтетических данных.

| Модуль | Работает в прототипе | На симулированных данных | Требует интеграции |
|---|---|---|---|
| **Карты для магазинов** (`leak-radar.js`) | номер карты на каждый магазин, вывод магазина по номеру, магазин в стоп-листе (1 клиент — «на проверке», 2 независимых — корреляция), общая точка компрометации от 3 клиентов, карта-приманка | номера карт, попытки списания, база утечек, клиенты симуляции в банке | виртуальные карты и токенизация в процессинге, отказ на авторизации, перевыпуск, база утечек от партнёров и АФЦ НБРК |
| **Безопасная сделка** (`safe-deal.js`) — «деньги ждут в банке до получения товара» | конверт и его статусы, проверка ссылки и сообщения продавца (`NX.scanText`, `NX.analyzeUrl`), «переведите напрямую», счёт продавца по стоп-листу и базе дропов, код сделки против скриншота «оплачено», признанные банком претензии двух независимых покупателей → стоп-лист | продавцы, трек-номера и «вручено», телефон продавца, срок конверта 10 минут | договор эскроу и правовая база, номинальный счёт в процессинге, API служб доставки, приложение банка у продавца |
| **Не стань дропом** (`mule-exit.js`) | оценка «транзитности» счёта (5 факторов, пороги 40 / 70), пауза перевода куратору, лист «Похоже, ваш счёт используют для чужих денег», выход в 3 шага (отмена → возврат тем же путём → сообщение банку), спор «Это ошибка», инцидент и узел «Вербуемый · сообщил сам» в графе | 6 переводов от незнакомцев (340 000 ₸), сообщение вербовщика, куратор — счёт из базы дропов | реальные входящие и исходящие переводы, возврат по исходным операциям в процессинге, решение банка о блокировке |
| **Кредитный замок** (`credit-lock.js`) | переключатель «Выключен / Только с моего телефона / Полный запрет», ослабление — через 24 ч и никогда во время звонка, заморозка заявок, вопрос «Это вы оформляете заём?», инцидент, счёт выплаты в стоп-листе, узел «Устройство-фабрика заявок» в графе | 3 заявки вымышленных МФО «А», «Б», «В», устройство «Android · Шымкент · новое», IBAN выплаты `KZ00 9999 …`, 5 других клиентов фабрики («синтетика») | кредитное бюро, МФО, государственный механизм добровольного отказа от займов, отказ на стороне кредитора |

Честные подписи новых функций (дословно в поповере):
- «Не стань дропом»: «Транзакции и отправители синтетические, пороги подобраны вручную, не обучены на реальных данных. Решение о блокировке принимает банк. Текст о законе — справочный». В UI нет номера статьи; под текстом о законе — «справка, не юридическая консультация».
- «Кредитный замок»: «Концепт интеграции: в демо нет подключения к кредитному бюро и госсервисам. Заявки и МФО вымышленные. Государственный механизм добровольного отказа от займов в РК существует — NEXUS добавляет к нему контекст атаки и связь со схемой, а не заменяет его».

Где найти: «Правила → Карты»; «Платежи → Покупка у частного лица»; «Помощь → Мне предлагают подработку с картой» (и вход через «Платежи → Проверить»:
сообщение с вербовкой даёт карточку «Это вербовка дропов» и кнопку «Посмотреть, что будет, если согласиться»); «Правила → Кредиты».
В банке — плитки «Новые функции» на «Сейчас» и фильтр «Тип» в «Инцидентах». На сцене карты и сделка — шаг 7 полной сцены; две новые защиты — строка на финальном слайде.
При включённом «Заблокировать всё» конверт безопасной сделки не открывается: новые переводы на паузе.

Браузер не слышит обычные телефонные звонки: в прототипе — микрофон браузера по согласию или демо-звонок. «Прослушиванием звонков» это не называем.

## Честные метрики

Все числа считает `bench.html` при открытии, ничего не захардкожено; после правки правил они изменятся, и **источник истины — сама страница**.
Ниже — значения, переписанные со страницы 17.11.2026 и перепроверенные 18.11.2026 после переделки интерфейса (стоп-лист браузера не учитывается). Корпус и звонки размечала та же команда, что писала правила.
Пороги «Не стань дропом» и «Кредитного замка» подобраны вручную и на бенче не измеряются.

**Сообщения** (`assets/data/sms-corpus.js`, `NX.scanText`):

| Набор | Порог | Recall | FPR | Precision |
|---|---|---|---|---|
| Основной, 120 (60 / 60) | ≥ 25 «предупреждение» | 100,0% (60/60) | 3,3% (2/60) | 96,8% |
| Основной | ≥ 55 «тревога» | 50,0% (30/60) | 0,0% (0/60) | 100,0% |
| Holdout другого стиля, 30 (17 / 13) | ≥ 25 | 52,9% (9/17) | 7,7% (1/13) | 90,0% |
| Holdout | ≥ 55 | 17,6% (3/17) | 0,0% (0/13) | 100,0% |

**Звонки** (`assets/data/call-scenarios.js`, 16 звонков: 11 мошеннических, 5 честных; порог тревоги ≥ 55 — как на сцене и на лендинге, на `bench.html` это значение ползунка по умолчанию):

| Показатель | Значение |
|---|---|
| Тревога до просьбы кода или перевода | **8 из 11** (RU 6 из 7, KZ 2 из 4); в остальных 3 тревога на той же реплике, что и просьба |
| Запас до просьбы кода | 1,5 реплики в среднем, медиана 2 |
| Пропущено мошеннических звонков | 0 из 11 |
| Тип атаки определён верно (`NX.Manip`) | 11 из 11 |
| Ложные тревоги на честных звонках | 2 из 5 |
| Ложные тревоги на честных звонках банка | без отметки 2 из 3 / с отметкой «звонит банк» 0 из 3 (разметку verified ставила команда — проверка логики, не качества) |

**Часть 3 · атака на сам NEXUS** (`assets/data/attack-corpus.js`): утечек из офлайн-приманки 0 из 40 ответов; пост-фильтр поймал
9 из 12 **симулированных** ответов «взломанной» LLM (3 пропуска — числа словами и выход из роли, показаны на странице);
отравление стоп-листа одной сессией — 1 запись, 1 источник, без удержания; XSS — 6 из 6 строк выведены как текст;
маскирование ПДн — 6 из 6; паритет маски сервер/браузер — 730 прогонов, 0 расхождений.

Выводы: на holdout обобщение слабое, поэтому сильное решение даёт сочетание компонентов (детектор, «обычный перевод», контекст звонка, правила клиента),
а не одно сообщение. План валидации на данных банка — бэктест, shadow-режим 4–6 недель, калибровка индекса — на `bench.html` и в `docs/QA.md`.

## Нейросеть на хостинге с PHP (бесплатно, Google Gemini)

Если сайт лежит на обычном хостинге (Plesk, без Node.js), реплики приманки и чат могут работать через `api/chat.php` и бесплатный ключ Google Gemini:

1. Получите ключ на aistudio.google.com (раздел API keys).
2. На сервере рядом с `api/chat.php` создайте файл `api/gemini-key.php` с одной строкой: `<?php return 'ВАШ_КЛЮЧ';` — в архив проекта он не входит и браузеру не отдаётся.
3. Откройте `https://ваш-сайт/api/chat.php` — должно быть `{"ok":true,...}`.

Сайт сам найдёт `api/chat` (Vercel/Netlify, Claude) или `api/chat.php` (PHP, Gemini); если ни один не отвечает — работает офлайн-движок. На бесплатном тарифе Google может использовать запросы для улучшения своих продуктов: туда уходят только реплики демо после маскирования номеров. Ответы нейросети не записаны заранее, поэтому их читает голос браузера, а не записи ElevenLabs.
